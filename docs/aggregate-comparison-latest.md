# 原生聚合 Dock 与桌面交接文档的差异

核对日期：2026-10-23。对照材料：桌面 handoff/PLAN.md（2026-10-20，39,221 字节）及其仓库留存副本。本轮从已部署的原生 0.8.80 优化到 0.8.81 / backend 0.5.66。用户最新反馈“做得还行”接受当前外观基础；0.8.79 的悬停、滑条、收起及开始菜单已明确验收。0.8.81用户随后确认“显示和操作都正常”，覆盖本轮新增详情及滑条/收起；技术检查与此实际反馈分别保留。

## 需求优先级

后续用户明确要求优先于旧 PLAN：恢复原生任务栏、托盘与固定列表；仅以聚合腰圆键替换小组件；保留旧触发角、Ctrl＋Alt＋Tab 和开始菜单定制；不显示星期；无内容模块收起；悬停面板直接控制音量、亮度、无线、热点及完整深浅主题。不能因旧文档称自己是唯一需求来源而恢复已被用户否定的独立 Dock。

## 技术来源与审查

直接复用的运行层仍是保留的原生上游模块，以及 aggregate/origins-latest.json 记录的本地0.9.8控制/绘制/采样代码；本轮没有引入第三方二进制。新增秒钟、CPU图形、节流与适配器匹配是本地适配。

GPU统计修正参考微软 DirectX 团队的 [GPUs in the task manager](https://devblogs.microsoft.com/directx/gpus-in-the-task-manager/) 对引擎利用率的说明，属于算法口径参考，不是复制其源码。原文的整卡/进程口径不能直接冒充本面板的3D专用计数器：此处明确标3D，并保留其他引擎占用未展示的边界。

可维护性：统计策略独立于UI，使用真实生产绘制器做离屏检查；原生已验收尺寸、输入和控制线程保持。边界：样本未就绪显示—，断电/插电不依赖电量变化，CPU趋势保留时间间隔，未知硬件不猜测。回归风险：仍通过BackendOnly保留控制器、Start和panels精确二进制；原生XAML完整初始化/退出测试、配置/固定列表/计划任务/组件健康均须核对。

## 验证与剩余差异

本轮技术检查包括隐藏原生XAML、生产Board生命周期、指标归并与时间边界、既有滑条命中/写入节流、只读真实设备采样、深浅色与100/125/150/200%离屏绘制。探针不显示测试窗口、不发送输入、不改变设备值。以正式验证记录为准，不将编译通过代替实际鼠标和动画验收。

没有为了文档逐字一致增加隐藏时的CPU采样。正式面板关闭后整个进程退出；开放时仍有50ms宿主/指针检查和约1秒指标采样，不能称零轮询。本轮也没有测出新的整体内存/耗电下降数值。

温度、媒体播放按钮、真实热点共享、多显示器迁移、睡眠后恢复和极端长内容仍是未完成或未实测边界。Liquid Glass实时折射是另一个待明确恢复的任务，不在本次界面优化中实施。

0.8.82后续修正：用户在0.8.81显示/操作验收后补充每次悬停有短暂繁忙光标。仅关闭面板启动时Windows默认反馈；面板二进制和上表功能保持0.8.81，未新增常驻采样。
