## 1. 产品定义

### 1.1 一句话

平时屏幕上什么都没有。鼠标碰到屏幕底边，一条毛玻璃胶囊 Dock 从底下弹起来，里面是应用图标、日期、电量和时间。时间同时是开始按钮。鼠标停在时间电量上，会弹出一张详情卡，显示其余系统信息和托盘图标。

### 1.2 用户和使用习惯

- 15–16 寸笔记本，只用自带屏幕。
- 打开程序靠点任务栏图标；切换窗口用 Alt+Tab，不点任务栏。
- 不需要任何消息提醒。
- 开始菜单、开始右键菜单（Win+X）、强制结束卡死的程序，偶尔用。其他入口（设置、音量、Wi-Fi、截图、回收站、显示桌面等）都不用。
- 嫌现在那条"放不下想要的信息，或者放下了太占地方"。

### 1.3 设计原则

1. **平时不占地方。** 收起时屏幕上不留任何东西，包括细线和小图标。
2. **一出来就看到最常用的。** 日期、电量、充电状态、时间在 Dock 上直接显示。
3. **其余的停一下再看。** 12 项不常看的信息全部放进详情卡，一次看全。
4. **动画流畅、不拖沓。** 升起带一点回弹，收起干脆利落。
5. **口味写死。** 没有设置页。

### 1.4 v1 范围

要做：
- 隐藏系统任务栏，退出或崩溃时能恢复。
- 碰底边呼出、离开收起、快捷键呼出、全屏时不呼出。
- 应用图标：固定的加正在运行的，点击、右键菜单、结束任务。
- 信息区：日期、电量和充电状态、时间按钮。
- 时间按钮：左键打开 Windows 开始菜单，右键打开自己画的开始右键菜单。
- 详情卡：秒、星期、农历、续航、CPU、内存、显卡、温度、网速、磁盘、音量、正在播放，以及托盘图标。
- 跟随系统深浅色，毛玻璃质感。

不做：
- 天气、日程、输入法状态、未读消息、下载进度、Wi-Fi 和蓝牙状态。
- 任何消息提醒，包括程序请求注意时任务栏按钮闪烁。
- 窗口标题、缩略图预览、跳转列表、当前窗口高亮。
- 多显示器支持、虚拟桌面、设置页、主题切换按钮。

## 3. 体验规格

### 3.1 三种状态

```
收起：屏幕上什么都没有。

展开：贴底悬浮，水平居中，离底边 8px，高 44px
  ( ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ┊ ▣    10/20   100%⚡   [15:46] )
    └──── 固定的应用 ────┘   └ 运行中但没固定的
                                └──── 信息区 ────┘ └ 时间按钮

详情卡：鼠标停在信息区 0.4 秒后，出现在 Dock 右端正上方
```

### 3.2 呼出与收起

**呼出条件（满足任一）：**
1. 鼠标光标到达主显示器最底下 2 个物理像素，水平位置不限。
2. 按 Win+T（见 4.7）。

**不呼出的情况：**
- 当前前台是全屏程序（看视频、放 PPT、玩游戏，判断方法见 4.6）。此时碰底边不呼出，但 Win+T 仍然可以呼出。
- 鼠标左键或右键正按着。这是为了避免拖选文字、拖动窗口到底边时 Dock 挡路。

**保持展开的条件（满足任一就不收）：**
- 鼠标在屏幕底部 92px 高的横带里，水平位置不限。92 = 底边距 8 + Dock 高 44 + 余量 40。
- 鼠标在详情卡上，或详情卡四周 8px 以内。
- 开始右键菜单、应用右键菜单正开着。
- Dock 是用 Win+T 呼出的，还没被取消（见下面）。

**收起：** 以上条件全都不满足，持续 500ms 后收起。期间只要有一个条件重新满足，就取消计时。

**用 Win+T 呼出时：** Dock 一直保持展开，直到再按一次 Win+T、按 Esc，或者在 Dock、详情卡、菜单以外的地方点了一下鼠标。

**点了开始菜单之后：** Dock 立即收起，避免和 Windows 开始菜单叠在一起。

### 3.3 Dock 布局与尺寸

从左到右：

| 元素 | 规格 |
|---|---|
| 左内边距 | 12px |
| 固定的应用图标 | 30×30，圆角 8，图标之间 8px |
| 分隔线 | 宽 1px，高 22px，细线色。只有存在"运行中但没固定"的程序时才出现 |
| 运行中但没固定的应用 | 同上，按启动先后排 |
| 应用区与信息区间距 | 12px |
| 日期 | 13px，次要文字色，例如 `10/20` |
| 电量 | 13px，正文色，例如 `100%`，插着电源时后面跟闪电图标 |
| 时间按钮 | 见 3.6 |
| 右内边距 | 12px（时间按钮有 -7px 右外边距，所以它离 Dock 右边缘只有 5px） |

信息区内部元素间距 10px。Dock 高 44px，圆角 22px（两端是半圆）。

**定位：** 展开到最终状态时，整条 Dock 在屏幕上水平居中，底边离屏幕底边 8px。
**动画锚点：** 升起和收起过程中，Dock 的右边缘位置固定，应用区宽度从 0 长到全宽，看起来是从右往左展开。
**宽度变化：** 展开状态下有程序启动或退出、图标增减时，图标用 3.11 的出现、消失动画，Dock 用 300ms 缓动重新居中。

### 3.4 应用图标

**来源：**
- 固定的程序：沿用现有那条任务栏的固定列表和存储方式。初始内容就是现在那条上的那些程序。
- 运行中的程序：会出现在 Windows 任务栏上的那些窗口（判断方法见 4.8），按程序归组。归组优先用 AppUserModelID，没有就用 exe 路径。固定项也按这两个来匹配。
- 排序：固定的按固定列表的顺序排；运行中但没固定的排在分隔线后面，按启动先后。现有那条如果已经支持拖动排序，就保留；没有就不做。

**外观：**
- 30×30 的程序图标，用程序自己的图标（取法见 4.9），不加底色。
- 运行中的程序，图标正下方有一个 4px 的圆点，圆心在图标底边以下 4px。颜色是正文色，55% 不透明度。没在运行的没有点。
- 鼠标悬停：图标上移 2px。悬停 0.6 秒后，在图标正上方显示程序名小标签，样式同菜单（3.10），13px。

**左键单击：**
- 没在运行：启动它。图标跳一下（动画见 3.11），等它的窗口出现后出现运行小点。
- 在运行、窗口不在前台：切换到这个程序最近用过的那个窗口，最小化的先还原。
- 在运行、窗口已经在前台：最小化这个窗口。

**右键菜单**（样式见 3.10，水平居中对齐图标，菜单底边离屏幕底边 60px，左右离屏幕边至少 8px）：

```
<程序名>                     ← 小标题，13px，次要文字色，不可点
打开新窗口
从任务栏取消固定 / 固定到任务栏   ← 看它当前是否固定
───────────                 ← 只有在运行时才有下面这部分
关闭窗口
结束任务                      ← 红色
```

- 打开新窗口：再启动一次这个程序。单实例程序会自己处理。
- 固定、取消固定：写入固定列表，立即生效。
- 关闭窗口：给这个程序的所有顶层窗口发 `WM_CLOSE`。
- 结束任务：结束这个程序的所有进程（同一个 exe 路径的进程），不弹确认，和 Windows 11 任务栏的"结束任务"一致。

### 3.5 信息区

- **日期：** `M/D`，月和日都不补零，例如 `10/20`、`3/5`。
- **电量：** 整数百分比，例如 `100%`。
  - 插着电源时，后面跟一个闪电图标（9×12，正文色）。没插电时不显示。
  - 没插电且低于 20%：数字和图标变成警告色。低于 10%：变成危险色。插着电时始终是正文色。
  - 这台机器没有电池时（理论上不会出现），不显示这一项。
- **悬停：** 鼠标停在日期、电量、时间按钮上任意一处满 400ms，弹出详情卡。离开信息区和详情卡 250ms 后详情卡消失。
- **右键：** 在信息区任意位置右键，都打开开始右键菜单。

### 3.6 时间按钮（开始按钮）

- 在 Dock 最右端，是和 Dock 同心的一颗小胶囊：高 34px，左右内边距 14px，圆角为高度的一半。
- 文字：24 小时制 `HH:mm`，例如 `15:46`、`09:05`。15px，半粗（600），等宽数字。
- 平时底色是"悬停色"，鼠标放上去变成"细线色"（更深一点），按下时缩到 95%（动画见 3.11）。
- **左键：** 打开 Windows 开始菜单（方法见 4.7），同时 Dock 立即收起，详情卡关闭。
- **右键：** 打开开始右键菜单（3.7）。

### 3.7 开始右键菜单

自己画，不调用系统的 Win+X 菜单，这样位置和样式可控。

- 位置：菜单右边缘和 Dock 右边缘对齐，菜单底边离屏幕底边 60px。
- 内容和分组按附录 B，每项的打开方式也在附录 B。
- "关机或注销"鼠标停住或点击时，向左展开子菜单：注销、睡眠、关机、重启。
- 最后加一组（附录 B 最后一行）："退出胶囊任务栏"。点了之后恢复系统任务栏并退出。
- 打开这个菜单时，详情卡关闭。

### 3.8 详情卡

```
  15:46:08            10月20日 周二
                      农历九月十一
  ─────────────────────────────────
  CPU    14%                ▁▂▃▂▅▃
  内存   92%           14.6 / 15.8 GB
  显卡   8%              Intel Iris Xe
  温度   CPU 61°　GPU 54°
  网速   ↓ 8.9 MB/s　↑ 101 KB/s
  磁盘   C 120 GB　D 340 GB       可用
  ─────────────────────────────────
  续航   插电中，已充满
  音量   60                 ▬▬▬▬▬───
  播放   ▶ 晴天 — 周杰伦
  ─────────────────────────────────
  后台   [QQ][微信][ChatGPT]       托盘
```

**位置和外观：** 宽 300px，圆角 14px，内边距上 12、左右 14、下 13。卡的右边缘和 Dock 右边缘对齐，底边离屏幕底边 62px（8 + 44 + 10）。用"浮层"毛玻璃（3.10）。

**排版：**
- 顶部：左边是带秒的时间，20px 半粗；右边两行，右对齐，13px 次要色，第一行 `10月20日 周二`，第二行 `农历九月十一`。下面一条细线，上下各 9px。
- 下面是两列：左列标签宽 2.6em，次要色；右列内容。行距 6px。每行右列可以有一个右对齐的次要内容（小曲线、容量、显卡名、"可用"、"托盘"）。
- 三组之间各有一条细线，上下 3px。

**每一行：**

| 标签 | 主内容 | 右侧次要内容 | 规则 |
|---|---|---|---|
| CPU | 整数百分比 | 最近 60 秒的曲线，84×16 | 每秒采样一次，后台一直采，这样一打开就有曲线。纵轴下限 0，上限取 50% 和这 60 秒最大值中较大的那个。线宽 1.5，强调色，下方填 15% 不透明度的强调色 |
| 内存 | 整数百分比 | `已用 / 总量 GB`，一位小数 | 百分比 ≥ 90 时用警告色 |
| 显卡 | 整数百分比 | 显卡名称，超过 16 个字符截断 | 3D 引擎占用 |
| 温度 | `CPU 61°　GPU 54°` | — | 拿不到的那一个显示 `—`，详见 4.10 |
| 网速 | `↓ 下载　↑ 上传` | — | 小于 1024 KB/s 显示整数 `KB/s`，否则一位小数 `MB/s` |
| 磁盘 | 每个本地硬盘 `盘符 剩余` | `可用` | 整数 GB；≥ 1000 GB 显示一位小数 TB |
| 续航 | 见下 | — | — |
| 音量 | 0–100 整数，静音时显示 `静音` | 宽 84、高 4 的音量条 | 只显示，不能拖 |
| 播放 | `▶ 标题 — 歌手`；暂停时 `⏸ 标题 — 歌手` | — | 没有在播放显示 `没有在播放`；太长时末尾省略 |
| 后台 | 托盘图标一排 | `托盘` | 见 3.9 |

**续航文字：**
- 插电、已充满：`插电中，已充满`
- 插电、正在充、能算出时间：`插电中，约 40 分钟充满`
- 插电、算不出时间：`插电中`
- 用电池、能算出时间：`约 3 小时 20 分`，不到 1 小时写 `约 38 分钟`
- 用电池、算不出时间：`正在估算`
- 没插电且低于 20% 时，这行用警告色

**刷新：** 详情卡显示期间每秒刷新一次。卡片不显示时，除了 CPU 采样和电量通知，其他数据都不读。

**交互：** 卡片本身不能点，只有托盘图标能点。点时间按钮、打开任何菜单、Dock 收起时，卡片立即消失。

### 3.9 托盘

- 位置：详情卡最后一行，图标 16×16，每个图标的可点区域 22×22，间距 8px。按图标出现的先后排。
- 内容：所有程序通过 `Shell_NotifyIcon` 注册的托盘图标（获取方法见 4.11），不包括 Windows 自带的音量、网络、电量图标。一个都没有时显示 `没有`。
- 左键单击、双击、右键单击：原样转发给图标所属的程序，由它自己处理。右键菜单是程序自己弹的原生菜单，样式不归我们管。
- 程序弹出自己的菜单或窗口期间，详情卡和 Dock 保持显示；菜单关闭后按正常规则收起。
- 鼠标悬停在托盘图标上 0.6 秒，显示程序提供的提示文字，样式同应用名小标签。

### 3.10 外观

**深浅色：** 跟随 Windows 的"选择 Windows 模式"（注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` 下的 `SystemUsesLightTheme`），收到 `WM_SETTINGCHANGE`（参数为 `ImmersiveColorSet`）时立即切换，不需要重启。

**字体：** `MiSans` → `HarmonyOS Sans SC` → `Microsoft YaHei UI` → `Segoe UI`，按顺序用第一个装了的。所有数字用等宽数字（tabular figures）。

**颜色：**

| 名称 | 浅色 | 深色 | 用在 |
|---|---|---|---|
| 正文色 | `#15171B` | `#ECEEF2` | 主要文字、运行小点 |
| 次要色 | `#5E6571` | `#9EA5B1` | 日期、卡片标签、次要内容 |
| 细线色 | `rgba(20,24,32,.10)` | `rgba(255,255,255,.10)` | 分隔线、时间按钮悬停底色 |
| 悬停色 | `rgba(20,24,32,.07)` | `rgba(255,255,255,.08)` | 时间按钮平时底色、菜单项悬停 |
| 警告色 | `#B97708` | `#E6A23A` | 低电量、内存 ≥ 90% |
| 危险色 | `#D23C33` | `#F06A60` | 极低电量、"结束任务" |
| 强调色 | `#0A7470` | `#3CC2B7` | CPU 曲线 |

**毛玻璃：**

| 名称 | 浅色底色 | 深色底色 | 背景模糊 | 用在 |
|---|---|---|---|---|
| Dock | `rgba(246,247,250,.62)` | `rgba(30,32,38,.58)` | 半径 22px，饱和度 160% | Dock |
| 浮层 | `rgba(248,249,251,.84)` | `rgba(34,36,42,.86)` | 半径 26px，饱和度 160% | 详情卡、所有菜单、名字小标签 |

- 描边：1px，浅色 `rgba(255,255,255,.6)`，深色 `rgba(255,255,255,.09)`。
- 阴影：两层，`0 10px 30px` 和 `0 1px 3px`，颜色浅色分别是 `rgba(15,20,30,.20)`、`rgba(15,20,30,.12)`，深色分别是 `rgba(0,0,0,.45)`、`rgba(0,0,0,.35)`。
- 实现方法和做不到时的退路见 4.4。

**菜单样式：** 最小宽 190px，圆角 10，内边距 5；菜单项 13px，内边距上下 5、左右 10，圆角 6，悬停时底色为悬停色；分隔线 1px 细线色，上下 4px、左右 6px；小标题 13px 次要色。

### 3.11 动画

缓动曲线（三次贝塞尔）：
- **回弹：** `(0.34, 1.42, 0.55, 1)`，会略微冲过头再回来

### 3.12 其他细节

- **焦点：** Dock、详情卡、名字小标签显示时都不抢焦点，当前正在打字的窗口不能失去焦点。菜单打开时可以拿焦点（为了接收 Esc 和"点别处就关"），关闭后如果用户没点别的窗口，把焦点还给打开菜单前的前台窗口。
- **层级：** Dock、详情卡、菜单都在最上层（topmost），不出现在 Alt+Tab 里。
- **Esc：** 菜单开着时，菜单有焦点，Esc 关闭菜单。用 Win+T 呼出的 Dock 开着时，由键盘钩子（4.7）收到 Esc，收起 Dock 并吞掉这次 Esc，不让它传给正在用的程序。其他时候不处理 Esc。
- **分辨率、缩放变化：** 重新计算所有位置和尺寸。
- **睡眠唤醒、资源管理器重启：** 见 4.2。
- **开机自启：** 沿用现有那条的方式。

### 4.1 先摸底（里程碑 M0）

开工前先读现有代码，回答下面几个问题，写进 `DECISIONS.md`，并用两三句话告诉主人：

1. 现有项目用的是什么语言、界面框架？哪些模块能直接复用？

3. 托盘图标准备用什么办法拿到（4.11）？

如果第 2 题的答案是"做不到"，按 4.4 的退路顺序选一个，告诉主人效果会差在哪里，等主人同意再继续。

### 4.2 隐藏系统任务栏与安全恢复

**启动时：**
1. 记下系统任务栏原来的"自动隐藏"状态（`SHAppBarMessage(ABM_GETSTATE)`）。
2. 把系统任务栏设为自动隐藏（`ABM_SETSTATE`，`ABS_AUTOHIDE`）。这一步让最大化的窗口铺满整个屏幕，底部不留空。
3. 隐藏系统任务栏窗口：`FindWindow("Shell_TrayWnd")` 后 `ShowWindow(SW_HIDE)`。如果存在 `Shell_SecondaryTrayWnd` 也一起隐藏。
4. 用 `SetWinEventHook(EVENT_OBJECT_SHOW)` 盯住这些窗口，被系统重新显示（比如按 Win 键时）就立即再隐藏。
5. 注册 `RegisterWindowMessage("TaskbarCreated")`。收到这个消息说明资源管理器重启了，重新执行第 2–4 步，并重新初始化托盘（4.11）。

**退出时**（正常退出、`WM_ENDSESSION`、菜单里的"退出胶囊任务栏"）：显示系统任务栏窗口，恢复原来的自动隐藏状态。

**看门狗：** 加一个很小的看门狗进程，由它启动任务栏主进程并等待它结束。
- 主进程正常退出：看门狗也退出。
- 主进程异常结束：1 分钟内最多重启 3 次。超过次数就恢复系统任务栏（显示窗口、恢复自动隐藏状态），然后退出。
- 这样无论怎么崩，主人都不会落到"没有任务栏"的境地。

### 4.3 窗口

- 每个毛玻璃面是一个独立的顶层窗口：Dock、详情卡、每个菜单、名字小标签。
- 扩展样式：`WS_EX_TOOLWINDOW`（不进 Alt+Tab）、`WS_EX_TOPMOST`、`WS_EX_NOACTIVATE`（菜单除外）。
- 开启每显示器 DPI 感知 v2。
- **建议做法：** Dock 窗口不要逐帧 `SetWindowPos` 移动，那样容易卡顿。把 Dock 窗口固定在屏幕底部：宽度为展开后的 Dock 宽度加左右各 24px，高度为 44 + 8 + 上方 24px（留给回弹冲高和阴影）。在窗口内部用合成层（Windows.UI.Composition 或 DirectComposition）做位移、缩放和宽度动画。
- **透明处不挡鼠标：** 收起时窗口隐藏，或者设为完全点穿（`WS_EX_LAYERED | WS_EX_TRANSPARENT`）。展开时，反正已经在定时读光标位置（4.5），光标在胶囊形状里面就去掉 `WS_EX_TRANSPARENT`，在外面就加上，这样窗口透明的边角不会挡住下面的窗口。`WS_EX_LAYERED` 和 4.4 第 1 种做法要求的 `WS_EX_NOREDIRECTIONBITMAP` 能否同时用，要在 M1 实测；冲突的话，把窗口四周的透明边距缩到最小（只留阴影需要的部分），并记进 `DECISIONS.md`。
- 详情卡和菜单同理：窗口比内容大出阴影的边距，边距部分要点穿。
- 以上是建议，不是唯一做法。目标是三条：动画流畅、透明处不挡鼠标、圆角和阴影边缘平滑。用了别的做法，记进 `DECISIONS.md`。

### 4.4 毛玻璃胶囊

目标：模糊背后的桌面内容，再叠上 3.10 的半透明底色，边缘是抗锯齿的胶囊形，外面有柔和阴影。

按优先顺序选第一个能做到的：

1. **合成层取背景（推荐）。** 窗口使用 `WS_EX_NOREDIRECTIONBITMAP`，并 `DwmSetWindowAttribute(DWMWA_USE_HOSTBACKDROPBRUSH, TRUE)`。用 Windows.UI.Composition 的 `Compositor.CreateHostBackdropBrush()` 拿到背后内容，叠一层高斯模糊和饱和度效果，再叠底色，用圆角矩形几何裁剪成胶囊形，阴影用合成层的投影。这样边缘平滑、阴影完整。这条路要先在 M1 用一个空胶囊做最小验证，确认在这台电脑上真的能模糊到背后的窗口。
2. **窗口亚克力 + 窗口区域。** 用 `SetWindowCompositionAttribute`（未公开的 API，`ACCENT_ENABLE_ACRYLICBLURBEHIND`）给窗口开亚克力，再用 `SetWindowRgn` 裁成胶囊形。缺点：边缘有锯齿，没有阴影。可以在内容层沿边缘画一圈 1px 半透明描边，盖住锯齿。
3. **没有模糊。** 只用半透明底色（不透明度提高到 0.85 左右），边缘平滑、带阴影，但背后不模糊。

选了 2 或 3，要告诉主人效果差在哪里，并记进 `DECISIONS.md`。
如果现有项目是网页类框架（Electron、Tauri、WebView2）：布局和动画可以直接参考 `prototype.html` 的 CSS；但网页里的 `backdrop-filter` 模糊不到桌面，真正的毛玻璃仍然要用上面的原生方法。

### 4.5 呼出检测

- 用定时器每 20ms 读一次 `GetCursorPos`，开销可以忽略。不要放一条透明的窗口去接鼠标，那样会挡住其他窗口最底下的点击。
- 光标 y 坐标 ≥ 主显示器底边 − 2（物理像素），并且 `GetAsyncKeyState` 显示鼠标左右键都没按着，并且不是全屏（4.6），就呼出。
- 收起计时按 3.2 的规则，同样在这个定时器里判断。
- 用 Win+T 呼出的状态下，也在这个定时器里检查：鼠标键刚按下、光标又不在 Dock、详情卡、菜单上，就收起。
- 展开时顺便在这个定时器里切换点穿状态（4.3）。

### 4.6 全屏判断

满足任一就算全屏，碰底边不呼出：
1. `SHQueryUserNotificationState` 返回 `QUNS_BUSY`、`QUNS_RUNNING_D3D_FULL_SCREEN` 或 `QUNS_PRESENTATION_MODE`。
2. 前台窗口不是最大化（`IsZoomed` 为假），它的矩形覆盖了整个显示器，而且它不是桌面（类名不是 `Progman` 或 `WorkerW`）。

注意：系统任务栏设为自动隐藏后，普通最大化窗口的矩形也会覆盖整个屏幕，所以必须用 `IsZoomed` 排除它。

### 4.7 开始菜单与快捷键

- **打开开始菜单：** 用 `SendInput` 模拟按下再松开左 Win 键。
- **Win+T：** 系统已经占用了这个组合键，`RegisterHotKey` 会失败。用低级键盘钩子（`WH_KEYBOARD_LL`）拦截 Win+T 并吞掉，切换 Dock 的显示状态。如果钩子不稳定，退而用 `RegisterHotKey` 注册 Win+Alt+T，并记进 `DECISIONS.md`、告诉主人。
- **吞掉 T 之后的坑：** 系统会以为用户只按了一下 Win，松开 Win 时弹出开始菜单。所以吞掉 T 时，要在 Win 松开之前用 `SendInput` 补发一个没有意义的按键（例如未分配的虚拟键 `0xE8`，按下再松开）。
- 钩子回调里只做标记，具体动作交给主线程，回调要立刻返回，否则全系统键盘会卡。
- 同一个钩子也负责 3.12 里 Win+T 呼出状态下的 Esc。

### 4.8 窗口与应用列表

- **会出现在任务栏上的窗口：** 可见；没有被隐藏（`DWMWA_CLOAKED` 为 0，这一条能排除后台的 UWP 窗口）；不带 `WS_EX_TOOLWINDOW`；没有所有者窗口，或者带 `WS_EX_APPWINDOW`。
- **变化通知：** `RegisterShellHookWindow`，处理 `HSHELL_WINDOWCREATED`、`HSHELL_WINDOWDESTROYED`、`HSHELL_WINDOWACTIVATED`、`HSHELL_RUDEAPPACTIVATED`，用来更新列表和记录每个程序最近激活的窗口。忽略 `HSHELL_FLASH`，因为不做提醒。
- **归组：** `SHGetPropertyStoreForWindow` 读 `PKEY_AppUserModel_ID`；没有就用进程的 exe 路径。
- **切换到窗口：** 用户刚点了我们的窗口，系统允许我们调用 `SetForegroundWindow`（我们的进程收到了最后一次输入）。窗口最小化的先 `ShowWindow(SW_RESTORE)`。如果还是切不过去，退而用 `SwitchToThisWindow`。
- **如果现有项目是 .NET：** 可以参考或直接使用开源库 ManagedShell（RetroBar 和 Cairo Desktop 用的就是它），它包含任务窗口列表、托盘、隐藏系统任务栏这几块。用之前确认它和现有代码兼容，并把选择记进 `DECISIONS.md`。

### 4.9 图标

- 普通程序：从快捷方式或 exe 取，用 `IShellItemImageFactory::GetImage`，请求 30 × 缩放比例的尺寸。
- 商店（打包）应用：用 `shell:AppsFolder\<AUMID>` 建 `IShellItem`，再用同样的方法取。
- 运行中的窗口如果提供了自己的图标（`WM_GETICON`），也可以用，但优先用程序本身的图标，保证和固定项一致。
- 缓存图标，只在缩放比例变化时重新取。

### 4.10 系统数据来源

### 4.11 托盘

这是技术上最难的一块，放在最后一个里程碑做。

- **原理：** 程序调用 `Shell_NotifyIcon` 时，系统把数据用 `WM_COPYDATA` 发给类名为 `Shell_TrayWnd` 的窗口。替代任务栏的常见做法是：自己也创建一个这个类名的窗口来接收这些消息，同时把消息转发给资源管理器原来的托盘，保证系统其他部分照常工作。启动时广播 `TaskbarCreated`，让所有程序重新注册自己的图标。
- **点击转发：** 根据图标注册时的版本（`NOTIFYICON_VERSION_4` 与旧版本），向它的回调窗口发送对应的消息：左键单击、双击、右键（`WM_CONTEXTMENU` 或 `WM_RBUTTONUP`）。转发前对图标所属进程调用 `AllowSetForegroundWindow`，否则它弹出的菜单和窗口跑不到前台。
- **参考：** ManagedShell 的托盘部分，RetroBar 用它在资源管理器运行的同时显示托盘。
- **做不出来的退路：** 详情卡里不显示"后台"这一行，告诉主人，并记进 `DECISIONS.md`。主人确认过，没有程序是只能从托盘操作的。

### 4.12 农历

- .NET 用 `System.Globalization.ChineseLunisolarCalendar`。闰年里 `GetMonth` 返回 1–13：设 `leap = GetLeapMonth(year)`，如果月份 `m == leap`，显示"闰（m−1）月"；如果 `m > leap`，实际月份是 `m − 1`。
- 其他语言用 Windows 自带的 ICU（`icu.dll`）的中国历法，或者内置 1900–2100 年的农历表。
- 月份名：正月、二月、三月、四月、五月、六月、七月、八月、九月、十月、冬月、腊月。闰月前面加"闰"。
- 日子名：初一到初十，十一到十九，二十，廿一到廿九，三十。
- 显示为 `农历` + 月份名 + 日子名，例如 `农历九月十一`、`农历闰六月初三`。
- 验证：2026 年 10 月 20 日是 `农历九月十一`。

### 4.13 性能目标

- 收起时：CPU 平均占用低于 0.5%。
- 展开时：动画不掉帧。
- 内存：说明现有框架的正常水平，比现有那条只能少不能多。

## 附录 C 原型说明

`prototype.html` 是在浏览器里模拟的，下面这些只为演示，真实版本不要照做：

- 左上角的说明卡，以及里面的主题、背景、模拟全屏、模拟低电量开关。
- 背景里的编辑器窗口。
- 顶部弹出的"演示：……"提示。
- 原型里的开始菜单是假的。真实版本打开 Windows 自己的开始菜单。
- 托盘图标的右键菜单是假的。真实版本由程序自己弹原生菜单。
- 按 T 键呼出，真实版本是 Win+T。
- 图标是彩色方块加一个字。真实版本用程序自己的图标，不加底色。
- 除了时间、日期、农历、电量，其他数字都是随机的假数据。
- 浏览器里的鼠标悬停提示，真实版本按 3.4、3.9 的名字小标签做。
- 原型里碰底边的判定是 4 像素，那是为了在浏览器里好触发。真实版本按 4.5，是最底下 2 个物理像素。

原型里能直接参考的：所有尺寸、颜色、毛玻璃参数、动画曲线和时长（已经抄进第 3 节）、详情卡的排版、各个菜单的样式和位置。
