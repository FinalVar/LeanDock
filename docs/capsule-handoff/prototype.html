开始菜单（演示，真实版本打开 Windows 自己的开始菜单）⏻

胶囊任务栏 · 原型 3

怎么用

  1. 鼠标碰到屏幕最底边（左右任意位置）：Dock 升起来；鼠标离开底部 0.5 秒后沉下去
  2. 按 T：模拟用快捷键呼出，再按一次收起
  3. 鼠标停在时间电量上：弹出详情卡，最下面一排是托盘
  4. Dock 最右端的时间按钮：左键开始菜单，右键开始右键菜单
  5. 右键应用或托盘图标：各自的菜单

背景

试之前先退出你现在那条任务栏，不然它挡在屏幕底边，会把鼠标抢走。按 F11 全屏看最接近真实；按 H 收起或打开这张说明。时间、日期、农历、电量是真的，其余数字是假的。
