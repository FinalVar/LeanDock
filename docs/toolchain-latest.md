# 独立工具链与旧安装清理

记录日期：2026-10-09。此项只更新构建入口、维护规则与本机安装状态，保留正在运行的 LeanDock 0.7.1 程序和配置。机器检查摘要见 toolchain-latest.json；它与此前的功能验收记录分别保存。

## 保留的依赖

- 运行：当前 LeanDock 控制进程及任务栏、开始菜单、快速设置组件，使用 Windows 系统 DLL。Windhawk 应用、服务、编辑器和引擎不属于运行或日常调试依赖。
- 构建：独立的 Clang 20.1.3 / MinGW / WinRT 工具链，来源为 Windhawk 1.7.3 随附的编译器包。保留 x64 所需文件及原许可证，移除 ARM、i686 目标库和 clangd。LeanDock 构建明确指定 x86_64-w64-mingw32，不依赖编译器的默认目标。
- 维护：upstream、vendor、生成器、作者与许可证说明、当前有效回退。它们不是待清理的旧软件安装。

所有构建和测试入口共享 build/toolchain-latest.ps1。查找顺序为显式 CompilerRoot、进程 LEANDOCK_COMPILER_ROOT、用户级同名环境变量；没有配置或缺少所需组件即报错，不回退到旧 Windhawk 路径。工具链不会自启或常驻，也不打包到部署目录和 Git 仓库。

本机工具链位于用户 Documents/Codex/Tools/LeanDockToolchain/latest，旁有 README.md 和迁移收据 latest.json。若需升级，先在新版本目录完成独立构建和相关回归，再改环境变量，保留此前可用版本作为回退。

## 清理结果

已运行 Windhawk 官方卸载程序，退出码为 0；随后核对并移除服务、卸载登记、快捷方式、剩余配置和缓存。三个已经被当前实现替代的独立安装 NativeClearTaskbar、NativeHotCorners 和 TaskbarDock 已移除，其自启引用、进程和原生桌面宿主中的模块先经核对。

清理时两个正在运行的 Codex 进程仍加载旧 Windhawk 引擎。该 DLL 为 979544 字节，连同其空父目录已通过 Windows 延迟删除机制登记为下次系统重启时清理，并读取登记结果确认。此项目前是“已登记”，不是“已删除”；没有终止当前 Codex 会话或强制卸载其模块，也没有增加等待清理的常驻任务。

旧工具及旧 Mod 源码保留为一份明确命名的压缩回退。每个归档都与原目录逐文件核对过内容哈希，清理前再次核对归档哈希。它们位于当前部署的 backups/retired-windhawk-20261009-071036，不作为运行入口或构建依赖。Windhawk 注册表恢复副本及本次操作证据只保留在本机，不上传仓库。

## 验证与边界

- 独立工具链保留的 7448 个文件与原件逐一进行 SHA-256 核对。
- 隔离目录中重新生成并完整构建控制进程、Explorer 组件、开始菜单组件、快速设置组件；检查四个成品的导入表，未新增第三方运行 DLL 依赖。
- 运行层 91 项、面板位置 72 项、系统动作 67 项检查通过，共 230 项、0 失败；系统动作测试没有向桌面发送输入。
- 原 Windhawk 编译器目录删除后，再次使用独立工具链编译并通过 72 项面板位置检查；显式路径、用户环境变量回退与无效路径拒绝均通过。
- 当前部署的四个程序文件和两份用户配置与清理前哈希一致，控制进程和任务栏所属 Explorer 的 PID 保持不变；只做维护文件同步，不部署这次验证构建的二进制。

完整构建成功证明这份本机工具链足以维护当前受支持系统，不证明其他编译器版本或其他 Windows 组件也兼容。本次没有新增真实点击、动画、登录或重启后的界面验收；延迟删除的最终完成仍需在下一次系统重启后确认。不能把组件就绪或早先用户反馈表述为本次的新界面测试。
