# 原生 Dock 聚合时间键 0.8.83

当前正式架构仍是原生任务栏。这个目录只负责悬停时出现的详情/常用控制面板，不是第二套 Dock。主时间键由 Explorer 内原生 XAML 绘制；应用按钮、固定排序、菜单和通知托盘保持原有对象。

## 当前行为

- 原小组件面板缩为72×46 DIP的时间/日期/电量环，无星期、独立电池按钮或常驻CPU圆环。旧分隔竖线已删除，右侧占位由100缩至78 DIP，键与底板实际中心对齐；保留原生大图标和托盘内边距。
- 单击时间键打开原生开始菜单，右键Win＋X；悬停400 ms打开详情。面板含音量、静音、亮度、Wi-Fi、蓝牙、深浅主题、热点及CPU/内存/网速等信息。
- 原生托盘图标留在Dock中，详情面板不接管、不转发通知图标。
- 鼠标移入面板可正常拖动滑条；离开键和面板250 ms后退出，拖动期间保持。单击过面板（拖滑条不算）后不再因离开而退出，切到别的窗口才算离开（0.8.105，见docs/panel-latest.md）。Esc、外部点击、锁屏、睡眠、宿主退出或DPI变化结束本次面板。
- 深浅主题复用原版完整主题和壁纸切换入口，不是暖色护眼模式。现有原生QuickTheme卡片挂接限制不被后台Active掩盖。
- 详情面板显示带秒时间与本次打开后最多60秒的真实CPU趋势；不增加隐藏时采样。显卡按LUID对应名称和各自3D占用，虚拟显示适配器没有3D计数器时不占行。磁盘每10秒读取、农历按日期缓存。主键尺寸和位置保持0.8.80；低电量环在插电后立即恢复正常颜色。

## 实现与退出责任

`src/cards-aggregate-latest.cpp`拥有原生键、可逆padding/background覆盖、系统电量事件和可见时的分钟计时器。`include/cards-aggregate-geometry-latest.h`用实际周长分段构建XAML矢量路径，100%闭合，未知电量不伪装成零。

真实悬停从Explorer正常权限启动固定的aggregate/latest.exe，先核对精确SHA。原生宿主在恢复子线程前发布PID与会话cookie，面板验证真实Explorer、PID、cookie和宿主句柄；不接受通用执行请求。面板不创建Shell_TrayWnd，不注册托盘，不调整AppBar或用户窗口。

0.8.82仅在原生宿主启动面板时加入STARTF_FORCEOFFFEEDBACK，抑制GUI进程默认的启动繁忙光标；SW_HIDE、暂停创建/发布所有者/恢复线程的顺序不变。不调用SetCursor覆盖系统光标，不通过常驻或提前启动掩盖反馈。面板二进制继续使用已验收0.8.81，controller/Start/panels也保持精确哈希。

0.8.83只改面板取数顺序和重复调用，显示内容不变。打开后第一轮先显示内存、电池、磁盘、音量、主题和热点等便宜读数；PDH显卡计数器（实测首次打开约0.3 s）和WMI亮度连接放到这次显示之后。CPU、网速和显卡的第二次采样提前到300 ms，之后仍是每秒一次。面板开着时，默认输出设备不变就复用同一个音量端点；热点每秒只查一次网络配置；亮度每3秒读一次，在面板里调节后立即读回。

面板开放时以50 ms检查指针离开/宿主状态；打开后第一次速率间隔为300 ms，之后约每秒采样一次信息。关闭后整个进程退出；不能把这些开放时检查称为零轮询。图形、音频、WMI/WinRT工作和取消位于子进程，异常退出不撤走原生任务栏；重新悬停可重新创建。初始化失败时原生键和托盘继续工作，PanelError保留诊断值。

`origins-latest.json`记录导入的0.9.8源码与SHA。保留原控件命中、75 ms滑条合并、请求/读回区分、异步取消及主题版本校验。新适配集中在原生XAML、父子生命周期和位置同步。

## 构建与维护

先运行aggregate/build-latest.ps1生成面板及SHA头，再运行build/latest.ps1 -BackendOnly，最后build/package-latest.ps1。构建使用独立LeanDockToolchain；PythonPath需指向真实Python解释器，不能使用WindowsApps安装别名。

BackendOnly保留当前已验收控制器、Start和panels的精确二进制。工作树中的hotcorners源码/生成器还有其他既存变更，本轮未覆盖或验收它们；需要重建这三个组件时先重新审核，已验收完整输入保存在0.8.78 accepted包。

更新仍经maintenance/latest.ps1 ValidateOnly与Update。可选面板进入签名/信任检查，Stop移除owner令牌后等待该精确面板进程结束，回退恢复旧组件并移除新文件。保留当前配置、计划任务、Windows固定列表和原0.9.8完整备份。
